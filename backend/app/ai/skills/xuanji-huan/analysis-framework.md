# Analysis Framework Reference

Detailed dimension definitions and analysis frameworks for each core capability.

---

## 1. Personality Profiling Dimensions

### Input Signals

| Signal Category | Specific Indicators |
|---|---|
| Dialogue content | Topics chosen, depth of disclosure, self-referencing frequency |
| Word choice habits | Formal/informal, hedging words, absolute words, emotional vocabulary density |
| Language style | Narrative vs analytical, abstract vs concrete, long vs short expressions |
| Logic & expression | Linear reasoning, circular reasoning, associative jumps, contradiction patterns |
| Emotional fluctuation | Stability across turns, reactivity to topics, recovery speed |
| Narrative style | Chronological, fragmented, defensive omissions, over-explanation |
| Behavioral tendencies | Approach vs avoidance, help-seeking vs self-reliance, compliance vs resistance |
| Avoidance patterns | Topic deflection, humor as defense, vague responses, subject changes |
| Repetitive focus | Recurring themes, returning topics, persistent concerns |

### Output Profile Dimensions

| Dimension | Description |
|---|---|
| Current psychological state | Overall mental condition at this moment |
| Emotional stability | Baseline emotional regulation capacity |
| Personality traits | Big Five tendencies, interpersonal style, coping preferences |
| Cognitive patterns | Attribution style, thinking flexibility, rumination tendency |
| Attachment style | Secure / Anxious / Avoidant / Disorganized tendencies |
| Security sources | What makes the user feel safe (relationships, control, predictability, etc.) |
| Self-worth | Self-evaluation patterns, confidence indicators, self-criticism level |
| Deep psychological motivations | Core drives beneath surface behavior |

## 2. Emotion Recognition Dimensions

### Emotion Type Spectrum

Primary emotions to identify:
- Joy, excitement, contentment, relief, gratitude, hope, anticipation
- Anxiety, worry, nervousness, dread, panic
- Anger, frustration, irritation, resentment, rage
- Sadness, loss, grief, disappointment, despair
- Shame, guilt, embarrassment, humiliation
- Loneliness, isolation, abandonment, disconnection
- Fear, helplessness, vulnerability, powerlessness

### Analysis Dimensions

| Dimension | Scale / Description |
|---|---|
| Emotion type | Primary + secondary emotions present |
| Emotion intensity | 1-10 scale or Light/Moderate/High |
| Emotion persistence | Momentary / Sustained / Chronic |
| Suppression level | None / Partial / Significant / Complete masking |
| Expression method | Direct / Indirect / Displaced / Somatized |
| Disguise behaviors | Humor masking pain, anger covering fear, withdrawal hiding hurt |
| Attachment patterns | How emotions connect to relational needs |
| Compensation mechanisms | What the user does to manage unmet emotional needs |

### Hidden Emotion Detection

Watch for unexpressed states:
- **Grievance** (wei qu): downplaying unfair treatment, self-blame for others' actions
- **Insecurity** (bu an): excessive reassurance-seeking, hypervigilance to rejection cues
- **Feeling ignored** (bei hu shi gan): over-explaining, attention-seeking patterns
- **Loss of control** (shi kong gan): micro-managing, rigid thinking, catastrophizing
- **Unmet needs** (xu qiu wei bei man zu): repeated indirect hints, passive complaints

## 3. Deep Need Analysis Framework

### Surface vs Depth Mapping

| Layer | Description | Example |
|---|---|---|
| Surface expression | What the user literally says | "I'm fine, just tired" |
| Immediate need | What they seem to want right now | Rest, reduced demands |
| Underlying need | What drives the immediate need | Feeling overwhelmed, loss of control |
| Core need | Fundamental psychological need | Being understood, being valued |

### Core Need Categories

Identify which primary need the user seeks:

| Need | Behavioral Indicators |
|---|---|
| Being understood | Extensive self-explanation, frustration when misinterpreted, "you don't get it" patterns |
| Being accepted | Self-deprecation before sharing, testing reactions, conditional disclosure |
| Being comforted | Dwelling on pain points, seeking emotional validation, sharing vulnerability |
| Being recognized | Achievement mentions, comparison references, seeking praise or acknowledgment |
| Being supported | Help-seeking, overwhelm signals, "I can't do this alone" patterns |
| Being accompanied | Prolonged engagement, reluctance to end conversation, loneliness cues |
| Being respected | Boundary assertions, autonomy emphasis, resistance to unsolicited advice |
| Being needed | Offering help, seeking purpose, value-through-contribution patterns |

### Defense Mechanisms to Identify

- Rationalization, intellectualization, projection
- Denial, minimization, displacement
- Humor as deflection, anger as protection
- Withdrawal, passive aggression, people-pleasing

## 4. Dynamic Emotion Modeling

### Emotion Logic Chain Construction

```
[Trigger Event]
    |
    v
[Psychological Interpretation]
  (How the user internally processes/explains the event)
    |
    v
[Emotional Reaction]
  (What emotions arise from their interpretation)
    |
    v
[Behavioral Expression]
  (How these emotions manifest in dialogue/behavior)
    |
    v
[Subsequent Impact]
  (How this cycle affects future interactions and emotional baseline)
```

### Modeling Dimensions

| Dimension | What to Track |
|---|---|
| Trigger points | Topics, words, scenarios that elevate emotional response |
| Relief conditions | What calms or stabilizes the user |
| High-risk topics | Subjects likely to cause emotional escalation |
| Safe zones | Topics and interaction modes the user finds comfortable |
| Recovery patterns | How the user naturally returns to baseline |
| Stress accumulation | Signs of mounting pressure over multiple interactions |
| Trend direction | Improving / Stable / Deteriorating emotional trajectory |

### Prediction Targets

| Prediction | Indicators |
|---|---|
| Escalation risk | Increasing intensity, shorter fuse, loss of hedging language |
| Collapse threshold | Cumulative stress markers, loss of coping language, despair signals |
| Avoidance probability | Topic dodging, conversation shortening, emotional flattening |
| Proactive expression probability | Increasing self-disclosure, direct emotional language, help-seeking |

## 5. Memory-Emotion Analysis

### Memory Categories

| Memory Type | Description | Impact on Interaction |
|---|---|---|
| Emotional memory | Events with strong emotional charge | Shapes emotional reactivity patterns |
| Traumatic memory | Past painful/harmful experiences | Creates avoidance triggers and hypervigilance |
| Safety memory | Positive, secure experiences | Provides emotional anchoring and trust basis |
| Subconscious memory | Influences behavior without awareness | Drives unexplained reactions and preferences |
| Reinforced memory | Repeatedly recalled or re-experienced | Strengthens associated emotional patterns |
| Attachment memory | Relationship-defining experiences | Shapes expectations in all relational interactions |

### Memory Impact Assessment

Identify which memories strengthen:
- **Security**: trust, openness, vulnerability tolerance
- **Insecurity**: hypervigilance, testing behavior, withdrawal
- **Trust**: disclosure willingness, reliance, cooperation
- **Avoidance**: topic dodging, emotional shutdown, distancing
- **Dependence**: excessive reliance, separation anxiety, clinging
- **Self-protection**: walls, deflection, preemptive rejection

## 7. Dream Interpretation Framework

### Analysis Approach

Combine these perspectives:
1. **Projective psychology**: Dream elements as projections of inner states
2. **Subconscious symbolism**: Common archetypal meanings (water=emotion, falling=loss of control, etc.)
3. **Emotional residue**: Dreams as processing of recent emotional experiences
4. **Internal conflict**: Dream scenarios reflecting unresolved psychological tensions

### Common Symbol Reference

| Symbol | Possible Associations |
|---|---|
| Water | Emotions, subconscious, cleansing, overwhelm |
| Falling | Loss of control, insecurity, fear of failure |
| Being chased | Avoidance, unresolved fear, anxiety |
| Flying | Freedom desire, escape wish, empowerment |
| Teeth falling | Self-image anxiety, powerlessness, aging fear |
| Enclosed spaces | Feeling trapped, restriction, safety seeking |
| Unknown figures | Unexplored aspects of self, projected fears/desires |

### Important Caveat

Dream interpretation provides **potential psychological reference only**. It is never presented as absolute conclusion. Always frame with: "This may suggest...", "One possible interpretation is...", "This could reflect..."
